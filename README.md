# Menú flipbook

Menú de comidas y bebidas en formato libro, con hojas de papel amarillo envejecido.
HTML, CSS y JS puros: no necesita instalar nada.

- **Escritorio:** libro abierto con dos páginas. **Celular:** una página por vez.
- Se pasa con los botones, tocando el borde de la página, deslizando o con las teclas ← →.
- El índice lleva directo a cada sección.

## Cómo editar el menú
Todo está en `menu.js`: nombre del local, secciones, platos, descripciones y precios.
Cada sección es una página (hasta unos 7 platos).

## Cómo publicarlo
En Vercel: *Add New → Project* → elegí este repositorio → *Deploy* (sin configuración).
También sirve GitHub Pages. Para probar en tu computadora: `python3 -m http.server`.
